### How I work

Everything sits on Claude Code and Claude Cowork. Underneath, the stack is React and Vite on the front end, Python for data and document pipelines, and Cloudflare Pages, Workers, and D1 for most of what I deploy, with Fly.io and Supabase where a project needs them.

I try to share the process and not only the finished thing.
